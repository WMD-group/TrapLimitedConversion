Installation
============

From source (recommended during development)::

   git clone https://github.com/WMD-group/TrapLimitedConversion.git
   cd TrapLimitedConversion
   pip install -e .

With doped integration::

   pip install -e ".[doped]"

Requirements
------------
- Python >= 3.10
- numpy, scipy, matplotlib, pandas
- Optional: `doped <https://doped.readthedocs.io>`_ for defect thermodynamics
